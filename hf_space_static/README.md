# Kidney CT Classifier Demo (browser-only)

Free, zero-install demo that classifies a kidney CT slice as Cyst / Normal / Stone / Tumor. Runs entirely in your browser via ONNX Runtime Web — no image is ever uploaded to a server. Research demo only, not a medical device.

No Grad-CAM heatmap in this version (browser-only inference keeps it simple and free). For the full-featured app with explainability and instructions to train on your own data, see the [GitHub repo](https://github.com/avantiwhenever/kidney-cancer-detection-demo).
